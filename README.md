<h1 align="center"> 전총명 </h1>

<h3>👋 소개</h3>
Java/Spring 백엔드 개발자입니다.<br>
크리니티에서 1년 9개월(2024.05~2026.01) 동안 대학·연구기관·공공기관용 클라우드 메일 서비스를 개발했습니다.<br>
고객사의 CS와 운영 이슈를 티켓으로 닫고 끝내지 않고, 원인을 찾아 제품 개선으로 이어 갑니다.<br>
개발 전에는 솔루션영업과 해외영업으로 약 4년간 B2B 고객과 일했습니다.

<h3>💼 경력 하이라이트</h3>
<ul>
	<li>13개 고객사 CS 채널 요청·장애를 개발 과제로 전환, 기능 개선과 제품 공통 수정 반영</li>
	<li>한국농수산식품유통공사 요청 SMS→MMS·대량발송 API 연동 (RestTemplate, CompletableFuture 병렬 발송)</li>
	<li>Spring AI PoC (다국어 번역·초안 작성·메일 요약·첨부파일 요약) → AI × Softwave 2025 (2025.12, 코엑스)에서 G-Cloud 공공메일 AI 기능으로 <a href="https://v.daum.net/v/Bn14HnMVOt?f=p">시연</a></li>
	<li>KISTI 프라이빗 클라우드 ELK/APM 구축 → 문의 대응 시간 약 30% 단축(체감 기준)</li>
	<li>KT Cloud·NCP CSAP 기준 Linux 서버 점검·보완</li>
</ul>
